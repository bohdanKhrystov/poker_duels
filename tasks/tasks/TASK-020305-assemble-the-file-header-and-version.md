## Goal

One function returns the entire TypeScript file as a string: a header naming the command that
regenerates it, the protocol version as a type alias, then every declaration.

## Files

| File | Action |
| --- | --- |
| `poker-server/src/main/kotlin/duels/poker/server/protocol/typescript/ProtocolTypeScript.kt` | modify |
| `poker-server/src/test/kotlin/duels/poker/server/protocol/typescript/ProtocolTypeScriptTest.kt` | modify |

## Scope

```kotlin
internal fun protocolTypeScript(): String
```

Exactly this shape, and nothing else:

```
// Generated by ./gradlew :poker-server:generateProtocolTypes -- do not edit by hand.
// Regenerate after any change to the Kotlin protocol; never hand-merge this file.

export type ProtocolVersion = 2;

<first declaration>

<second declaration>
...
```

- The header is the first two lines, plain ASCII (no em dash): later tickets `grep` for it from a
  shell, and this file is machine output, not prose.
- `export type ProtocolVersion = ...;` is built from the `PROTOCOL_VERSION` constant. Do not write
  the digit. The emitted **file** will of course contain the literal `2` — that is the point: a
  future version bump that skips regeneration is exactly the drift `TASK-020308` fails the build on.
- Declarations are `protocolDeclarations().joinToString("\n\n") { it.text }`, in the order the walk
  returned them.
- `\n` only — never `\r\n` — and the string ends with exactly one `\n`.

## Out of scope

- Writing the string anywhere, and any Gradle task — `TASK-020307`.
- Asserting anything about discriminators — `TASK-020306`.

## Tests

Added to `ProtocolTypeScriptTest`.

| Test | Proves |
| --- | --- |
| `theHeaderNamesTheRegenerationCommand` | line 1 of the output contains `./gradlew :poker-server:generateProtocolTypes` and the word `Generated` |
| `theProtocolVersionIsATypeAlias` | the output contains the line `export type ProtocolVersion = $PROTOCOL_VERSION;`, built from the constant so a future bump does not require editing this test |
| `theFileUsesLfAndEndsWithASingleNewline` | the output contains no `\r`, ends with `\n`, and does not end with `\n\n` |
| `everyDeclarationReachesTheFile` | for each `TypeScriptDeclaration` from `protocolDeclarations()`, the output contains its `text`; the list is not empty |
